# Stanford CS231N: Deep Learning for Computer Vision

📚 My study notes, assignment implementations, and extended experiments 
from Stanford CS231N (2023/2024 version).

## 🎯 Purpose
Building solid foundations in computer vision and deep learning, 
with a focus on understanding core concepts from first principles.
Extended experiments explore applications in **medical imaging** — 
my primary research interest.

## 📂 Repository Structure

| Folder | Description |
|--------|-------------|
| `notes/` | Detailed lecture notes with personal insights |
| `assignments/` | Complete assignment solutions with analysis |
| `extensions/` | Self-designed experiments beyond course scope |
| `implementations/` | Classic architectures built from scratch |
| `cheatsheets/` | Quick reference materials |
